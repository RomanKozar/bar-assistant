# Bar Assistant

Помічник бармена: каталог рецептів, склад станції і робоче меню з того, що реально є на полиці.

## Запуск

```bash
npm install
npm run dev
```

Збірка: `npm run build`. Перевірка типів і лінт: `npm run build` / `npm run lint`.

## Що вже є

- **Шоти**, **алкогольні коктейлі**, **безалкогольні коктейлі** — три головні розділи
- Рецепти з мірами, методом і кроками
- **Склад бару** — наявність зберігається в `localStorage`

Стартовий склад уже заповнений як типова станція (джин, бурбон, ром, текіла, вермут, цитрус, сироп тощо).

## Структура

```
src/
  data/          рецепти, інгредієнти, підписи
  pages/         екрани
  components/    картка коктейля і каркас
  context/       стан складу бару
  lib/           підрахунок «що можна змішати» і збереження
```

Далі зручно додавати власні рецепти в `src/data/cocktails.ts` і позиції в `src/data/ingredients.ts`. Пізніше цей шар можна замінити на API.
